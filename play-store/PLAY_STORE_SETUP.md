# Publishing Vriddhi to Google Play Store (Android Mobile)

Vriddhi is now configured as an installable Progressive Web App (PWA) with a Web App Manifest (`Vridhi--2-main/manifest.webmanifest`), Service Worker (`Vridhi--2-main/sw.js`), 192x192 / 512x512 / maskable PNG icons (`Vridhi--2-main/icons/`), and Android Digital Asset Links (`Vridhi--2-main/.well-known/assetlinks.json`).

This lets you package Vriddhi as an Android App Bundle (`.aab`) using **Trusted Web Activity (TWA)** via Google's **Bubblewrap CLI** or **PWABuilder**.

---

## Prerequisites
1. Your live site must be deployed over **HTTPS** on a permanent domain (for example, `https://shishirb53a.github.io/Vridhi53a/` or your custom domain). Do **not** use a temporary preview URL.
2. **Java JDK 17** and **Android SDK** (Bubblewrap can automatically download both on your first run).
3. A **Google Play Console** developer account.

---

## Option A: Build `.aab` with Bubblewrap CLI (Recommended)

1. **Verify `play-store/twa-manifest.json`:**
   If you use a custom domain instead of `shishirb53a.github.io/Vridhi53a/`, update `host`, `startUrl`, `iconUrl`, `maskableIconUrl`, `webManifestUrl`, and `fullScopeUrl` in `play-store/twa-manifest.json`.

2. **Initialize and build on your machine:**
   ```bash
   npm install -g @bubblewrap/cli
   cd play-store
   bubblewrap init --manifest="https://shishirb53a.github.io/Vridhi53a/manifest.webmanifest"
   bubblewrap build
   ```
   - When prompted, create an upload keystore (`android.keystore`) and **store the keystore file and passwords safely offline** (never commit `android.keystore` to Git).
   - `bubblewrap build` produces `app-release-bundle.aab` (for Play Store) and `app-release-signed.apk` (for direct USB/phone testing).

3. **Connect Digital Asset Links (removes the browser address bar in the Android app):**
   - Get the SHA-256 fingerprint of your keystore:
     ```bash
     keytool -list -v -keystore android.keystore -alias vriddhi-upload
     ```
   - After uploading your `.aab` to Google Play Console (Internal Testing), also copy the **App signing key certificate SHA-256** from **Play Console → Test and release → Setup → App integrity**.
   - Put both SHA-256 fingerprints into `Vridhi--2-main/.well-known/assetlinks.json` (matching your `packageId` in `twa-manifest.json`), commit, and push to deploy the updated site.
   - Verify it is live and returns JSON at:
     `https://<your-domain>/.well-known/assetlinks.json`

---

## Option B: Build `.aab` with PWABuilder (No local Android SDK needed)

1. Push your updated `Vridhi--2-main/` folder so the PWA is live over HTTPS.
2. Open **https://www.pwabuilder.com/** and enter your live URL.
3. Click **Package for stores → Android → Generate Package**.
4. Enter `com.vriddhi.planner` as the Package ID and download the zip containing the `.aab`, keystore, and `assetlinks.json`.
5. Place the downloaded `assetlinks.json` into `Vridhi--2-main/.well-known/assetlinks.json` and deploy it.

---

## Testing on an Android Phone Before Play Store Review
- You can test directly in **Chrome on Android** by visiting your HTTPS URL and tapping **Install App** in the header (or Chrome menu → *Install app*).
- Or sideload `app-release-signed.apk` generated by `bubblewrap build` onto an Android device with USB debugging enabled (`adb install app-release-signed.apk`).
